The Partial-Pooling Dial

Eight schools, each with an estimated effect yi and a standard error σi. The hierarchical model lets the true effects θi differ with spread τ. At τ = 0 every school gets the common mean; as τ grows each keeps its own estimate. The data choose τ through p(τ | y).

Population level

How different the true school effects are allowed to be. 0 forces one common effect (complete pooling).

The hyperprior τ ~ U(0, A); the slide uses 100. Small A cuts off the right tail of p(τ | y).

Data

Thought experiment: every σi² divided by κ, as if each school had κ times the students. Log scale 0.25 to 16; the middle mark (κ = 1) is the data.

Marginal posterior p(τ | y)

Belongs to: Class 7 notes, Notas/L07/ (hierarchical linear models, L07-04-hierarchical-linear-models.md).

Model (HLM.pdf slide 23): yi | θi ~ N(θi, σi²), θi ~ N(μ, τ²), μ ~ N(0, 10⁶), τ ~ U(0, A), i = 1, …, 8, with di = σi²/κ. Given τ: wi = 1/(di + τ²), Vμ = 1/(10⁻⁶ + Σwi), μ̂ = VμΣwiyi, Bi = di/(di + τ²), E(θi | y, τ) = (1 − Bi)yi + Biμ̂, Var(θi | y, τ) = (1 − Bi)di + Bi²Vμ. Marginal: y | τ ~ N₈(0, diag(di + τ²) + 10⁶·11′), evaluated with the matrix-determinant lemma and Sherman–Morrison; p(τ | y) ∝ 1{τ < A} × that density. Fully Bayes E(θi | y) = ∫ E(θi | y, τ) p(τ | y) dτ by the trapezoid rule on the same grid. Data: the slide's table (Rubin 1981, as printed). Default τ = 5.2 is the posterior median 5.23 at the defaults, rounded to the slider step.

Books: Greenberg (2007) §4.6 Hierarchical Models, pp. 52–53 (the extra level θ₀ and why it is not identified on its own); §9.3 Panel Data, pp. 144–149 (random effects bi).
