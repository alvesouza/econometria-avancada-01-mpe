The Four Estimators

Four ways to estimate the upper bound θ of a U(0, θ) sample, compared by mean squared error. Move θ and n to see which wins and how fast, and slide c to find the best multiple of the maximum.

The population

The true bound of U(0, θ). Every MSE scales with θ², so it moves the levels but never the ranking.

Number of draws. MSE falls like 1/n for the x-based pair and like 1/n² for the maximum-based pair.

Scaling the maximum (extension)

The estimator c·x₍ₙ₎. c = 1 is the MLE θ̂₂; c = (n+1)/n is the unbiased θ̂₄.

A snapped c follows n until you move the slider.

MSE against sample size

θ̂₁ = x  θ̂₂ = x₍ₙ₎  θ̂₃ = 2x  θ̂₄ = (n+1)/n·x₍ₙ₎. Log scale, fixed so θ shifts the curves. Gold dashed: n = 2, the last tie.

MSE of c·x₍ₙ₎ against c

θ²[c²n/(n+2) − 2cn/(n+1) + 1], at the current θ and n. Gold lines: the MLE, the unbiased scale and the minimum-MSE scale c*.

Means, spreads and errors, as on slides 3 and 12

Exact values at the current θ and n. MSE = V(θ̂) + [E(θ̂) − θ]² (slide 4).

Belongs to: Class 1 notes, Notas/L01/ (L01-05, comparing estimators by MSE and the bootstrap).
Model: x₁, …, xₙ iid U(0, θ); θ̂₁ = x, θ̂₂ = x₍ₙ₎, θ̂₃ = 2x, θ̂₄ = (n+1)/n·x₍ₙ₎. MSE₁ = θ²(1+3n)/(12n), MSE₂ = 2θ²/[(n+1)(n+2)], MSE₃ = θ²/(3n), MSE₄ = θ²/[n(n+2)]; x₍ₙ₎/θ ~ Beta(n, 1). Bootstrap point mass P*(x*₍ₙ₎ = x₍ₙ₎) = 1 − (1 − 1/n)ⁿ → 1 − e⁻¹ ≈ 0.632. Ties are decided in exact integer arithmetic (all four MSEs times 12n(n+1)(n+2)/θ²), so the n = 1 and n = 2 ties are exact.
Extension beyond the slides: the c·x₍ₙ₎ family, MSE(c) = θ²[c²n/(n+2) − 2cn/(n+1) + 1], minimised at c* = (n+2)/(n+1) with MSE = θ²/(n+1)², is not in the deck. It follows from E(x₍ₙ₎) = nθ/(n+1) and V(x₍ₙ₎) = nθ²/[(n+1)²(n+2)] on slide 3. The slider spans 0.80–1.40; for n ≤ 2 the unbiased or minimum-MSE scale lies above 1.40, and the buttons still set it exactly (the slider then rests at its end).
