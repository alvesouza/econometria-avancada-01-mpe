# Listas/data: provenance

One line per data file: file, source, how obtained, date, used by.

- `kielmc.csv` (321 x 25): KIELMC data set of Wooldridge, *Introductory Econometrics* (Kiel and McClain 1995), exported from the `wooldridge` Python package v0.5.0 (`wooldridge.data("kielmc")`, PyPI) on 2026-10-25. Used by `L05-book-exercises-check.py` (W 13.2, 13.C3). CARD for L05 is read from `Aula/class-05-06/materials/card.csv` (identical to `wooldridge.data("card")` to 5e-7), not copied here.
- `Boston.csv` (506 x 13): ISLP Boston housing data, downloaded from https://raw.githubusercontent.com/intro-stat-learning/ISLP/main/ISLP/data/Boston.csv on 2026-10-25. Used by `L01-book-exercises-check.py` (ISLP 5.9). L01 also uses PHILLIPS via `wooldridge.data("phillips")` (package v0.5.0, not copied here) and the 2004 unemployment rate 5.5 (BLS annual average; FRED UNRATE monthly 2004 values, fetched 2026-10-25, average 5.54) for W 11.C8.
- `babies.data` (1236 x 7): StatLabs "Birth weight II" (Nolan and Speed, *Stat Labs*), downloaded from https://www.stat.berkeley.edu/users/statlabs/data/babies.data on 2026-10-25. Used by `L03-book-exercises-check.py` (Greenberg 8.1). L03 also uses the British coal-mining disaster counts 1851-1962 (Carlin, Gelfand and Smith 1992), embedded in that script (same series as `Notas/L01/figures/make_figures.py`; totals 112 years, 191 disasters, 125 in 1851-1890, matching the lecturer's slides). Tsay Exercises 12.1-12.3 are analytical: no Tsay data file used.
- `Default.csv` (10000 x 4), `Weekly.csv` (1089 x 9), `Auto.csv` (392 x 9, rows with missing horsepower already removed), `Wage.csv` (3000 x 11): ISLP data sets, downloaded from https://raw.githubusercontent.com/intro-stat-learning/ISLP/main/ISLP/data/<name>.csv on 2026-10-25. Used by `L02-book-exercises-check.py` (ISLP 5.5, 4.13, 4.14, 7.6). L02 also uses `Boston.csv` above (ISLP 7.9, same file, byte-identical download) and PNTSPRD, CRIME1, FERTIL1 via `wooldridge.data()` (package v0.5.0, not copied here) for W 17.C1, C4, C5.
- `disco.xls` (104 x 3), `inibina.xls` (32 x 4), `endometriose2.xls` (1872 x 24, sheets "dados" and "descricao"): Morettin & Singer, *Estatística e Ciência de Dados*, data files of http://www.ime.usp.br/~jmsinger/MorettinSinger/<name>.xls (the address given in the book, §1.8). The site was unreachable on 2026-10-25; downloaded from the Internet Archive snapshots of 2022-05-26 (https://web.archive.org/web/20220526213824id_/https://www.ime.usp.br/~jmsinger/MorettinSinger/disco.xls, and the same date for the other two files) on 2026-10-25. `disco` matches the book's Tabela 8.1 (104 joints, 29 displaced). Used by `L02-book-exercises-check.py` (MS 8.9, 8.4, 8.6, 8.11).
- L07 (`L07-book-exercises-check.py`): Greenberg 8.1/8.3 use `babies.data` above (same StatLabs URL, re-downloaded 2026-10-25; 1,174 complete cases after dropping the codes 999/99/9). W 12.C2, 12.C10, 17.C2, 17.C3, 17.C9, 14.C5 and the Greenberg 8.6/8.7 illustrations read WAGEPRC, PHILLIPS, LOANAPP, FRINGE, APPLE, WAGEPAN and MROZ via `wooldridge.data()` (package v0.5.0, not copied here).
