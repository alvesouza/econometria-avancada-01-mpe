Explain and discuss in depth the bootstrap as one topic across Class 1 and Class 2: what resampling the data can and cannot estimate. Use the uploaded slides `Aula_class-01_comparing-estimators-MSE-slides.pdf` (slides 13–19), `Aula_class-01_Class1-comparing-estimators-MSE.pdf` and `Aula_class-02_motorcyle-polynomialregression.pdf` (slide 11), with `Livro_James, Witten, Hastie, Tibshirani, Taylor - An Introduction to Statistical Learning with Applications in Python (2023).pdf` (§5.2, pp. 212–215; Exercise 5.2), `Livro_Morettin, Singer - Estatística e Ciência de Dados (versão preliminar, abril 2021).pdf` (§10.5, note 3, pp. 339–340; §B.6, pp. 467–472) and `Livro_Bolfarine, Sandoval - Introdução à Inferência Estatística (2010).pdf` (Ex. 3.1.3, Ex. 5.5.2). The listeners know the Monte Carlo study of the four U(0, θ) estimators and the 0.632 point mass. Go deeper into why it happens, what repairs it, and how intervals and bands are built. It covers:

The plug-in idea: The bootstrap is Monte Carlo run on the empirical distribution F̂n in place of the unknown F, so it carries two errors: F̂n against F, which only more data cure, and a finite B, which more resamples cure. Derive the bootstrap SE, ISLP (5.8). In ISLP's portfolio example (α = 0.6), 1000 simulated data sets give an SD of 0.083, while 1000 resamples of one data set give 0.087. Morettin and Singer apply the same steps to the sample median and suggest B = 200.

What one sample contains: In the Class 1 deck, ten draws from U(0, 3) happen to lie in [1.35, 2.33], so every bootstrap SD is too small: 0.117 against 0.274 for x̄. For x̄ the gap then closes, 0.113 against 0.122 at n = 50 and 0.089 against 0.087 at n = 100. Discuss why no resampling scheme recovers spread the sample lacks.

The failure for the maximum: Derive P(x*_(n) = x_(n)) = 1 − (1 − 1/n)^n, which is 0.651, 0.636 and 0.634 at n = 10, 50, 100, against the deck's 0.666, 0.622 and 0.632, each within about one Monte Carlo SE of 0.015. Explain the deeper reason through the Monte Carlo study's rates: the max-based MSEs fall like 1/n², and n(θ − x_(n))/θ converges to an Exponential(1), a non-normal limit at rate n, not √n. The empirical cdf has no mass above x_(n), so the resampled maximum has a step-function law with a 63% jump. Show why the error has no fixed sign: max-based bootstrap SDs are 0.041 against 0.058 at n = 50 but 0.036 against 0.029 at n = 100. Tie this to Bolfarine Ex. 3.1.3: the same boundary that keeps the score from vanishing breaks the bootstrap.

Two repairs: The parametric bootstrap draws from U(0, θ̂4). At n = 10 with θ̂4 = 2.568 it reproduces the plug-in SDs 0.234 and 0.213, still below the true 0.274 and 0.249 because θ̂4 is low; at n = 50 and 100 it lands on theory. Contrast the Bayesian route of Classes 3+4 (Bolfarine Ex. 5.5.2): a Pareto(θ0, α0) prior gives a Pareto(max{x_(n), θ0}, α0 + n) posterior, which never goes below the data's maximum. On a seeded n = 50 sample with x_(50) = 1.8923, the posterior mean is 1.9308 and the 90% interval (1.8942, 2.0089) covers θ = 2.

Intervals: Compare the normal interval θ̂ ± 1.96 SE with the percentile interval. In the lecturer's 50-observation Gaussian example the bootstrap interval for μ nearly equals the exact t interval (−0.159, 0.360). For σ², however, the bootstrap law looks Gaussian while the exact χ² interval (0.593, 1.321) is skewed, and the gap closes only as n grows.

Bands: For the Class 2 motorcycle fit (polynomial order 12, B = 1000), explain the pairs bootstrap and the pointwise 95% percentile band, against the formula band ±2√(ℓ0'σ̂²(X'X)⁻¹ℓ0) of ISLP (7.2). Resampling pairs respects heteroskedasticity, so the band widens in the noisy region and flares at both ends. It omits model-selection uncertainty, because the order stays at 12; rerunning cross-validation inside each resample would add it. Finally, contrast the bootstrap's equal weights 1/n with the weights f/g of sampling importance resampling (Morettin and Singer §B.6).

Python walkthrough: In words, describe resampling indices with numpy.random.default_rng, the exact bootstrap cdf of the maximum, F̂n(t)^n, a parametric loop from U(0, θ̂), and a pairs bootstrap of a statsmodels polynomial fit summarised with numpy.percentile.

Close with misconceptions: more resamples do not fix an inconsistent bootstrap, resampling creates no new information, and a pointwise band is not a simultaneous one.
