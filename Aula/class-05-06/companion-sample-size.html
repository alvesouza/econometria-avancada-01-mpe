Bigger Sample, Same Bias

500 simulated studies, each comparing treated with untreated people. Grow the sample and the confidence intervals shrink. Whether they shrink onto the true effect depends only on how people were assigned.

Belongs to: Classes 5+6 notes (Aula/class-05-06/potential-outcomes.ipynb). The point is MHE's: a bigger sample buys precision, but only the design, an ideal experiment (Ch. 1, pp. 3–7) or random assignment (§2.2, p. 12), removes selection bias. NHIS example: t = 58.9 on a biased gap, p. 10.
Data-generating process (illustrative, declared here and not taken from MHE): the same model as the Selection Bias Decomposer, with π = 0.5 and γ = 0 fixed so the effect is homogeneous (ATT = ATE = τ). Y₀ ~ N(5, σ²); D = 1{λz + √(1−λ²)ν > 0}; Y = Y₀ + τD. Population naive gap = τ + 4σλφ(0). Each study draws N people (seeded PRNG, so moving a slider does not reshuffle) and reports the difference in means with an unpooled SE. The band in the right panel uses the exact within-group variance σ²(1 − 0.6366 λ²), where 0.6366 = (φ(0)/0.5)², and SE = 2σ√(v/N). Theoretical coverage = Φ(1.96 − SB/SE) − Φ(−1.96 − SB/SE).
