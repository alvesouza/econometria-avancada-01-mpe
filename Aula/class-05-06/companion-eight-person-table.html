Belongs to: Classes 5+6 notes (Aula/class-05-06/potential-outcomes.ipynb) and the class-01 explainer video (Videos/class-01-potential-outcomes, beats B05–B17), which use the same table.
Model: switching equation Y = Y₀ + (Y₁ − Y₀)D (MHE eq. 2.1.1, p. 11); naive gap = ATT + selection bias (MHE p. 11); with π = k/8 the share treated, naive gap = ATE + SB + (1 − π)(ATT − ATU), which is the standard extension that follows from ATE = π·ATT + (1−π)·ATU. All numbers on this page are exact finite-population values. The distribution enumerates all C(8, k) assignments; nothing is sampled except the "Random draw" button.
Table: invented for teaching; it is not data. ATE = 1.125, and under the self-selection preset ATT = 2, ATU = 0.25, SB = −5, naive gap = −3.
